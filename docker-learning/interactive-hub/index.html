    💡 The Golden Rule of Docker Caching:

    Docker executes instructions top to bottom. If a line's checksum changes (like COPY . . when code changes), that layer and EVERY SINGLE LAYER BELOW IT loses its cache. Always put slow dependencies (RUN npm install, RUN pip install) above source code copies!

    💡 Flag Anatomy Cheat-Sheet:

    • -d (Detached): Starts in background. Omit it if you want to see live logs in stdout.
    • --rm: Garbage collects container disk space when stopped. Crucial for temp tasks!
    • -p 8080:80: Left is Host (your laptop), Right is Container.
    • -v my-vol:/app: Persists files beyond container destruction.
