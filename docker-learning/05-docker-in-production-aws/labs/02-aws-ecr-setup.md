# Lab 02: AWS ECR (Elastic Container Registry) Setup & Push

### Objective
Configure AWS CLI, authenticate Docker with your private AWS ECR registry, and push an enterprise-grade container image.

---

### Prerequisites
1. An AWS Account.
2. AWS CLI installed (`aws --version`).
3. Your AWS credentials configured via `aws configure` (or AWS IAM Identity Center).

---

### Step 1: Create an ECR Repository
In PowerShell or AWS CloudShell:
```powershell
# Set your AWS region (e.g., us-east-1 or ap-south-1)
$AWS_REGION = "ap-south-1"
$REPO_NAME = "production-api"

aws ecr create-repository `
  --repository-name $REPO_NAME `
  --region $AWS_REGION `
  --image-scanning-configuration scanOnPush=true
```
*(Notice `scanOnPush=true`: AWS will automatically scan every image you push for Linux CVE vulnerabilities!)*

---

### Step 2: Get your AWS Account ID
```powershell
$ACCOUNT_ID = (aws sts get-caller-identity --query Account --output text)
$ECR_REGISTRY = "$ACCOUNT_ID.dkr.ecr.$AWS_REGION.amazonaws.com"
Write-Host "Your ECR Registry URL is: $ECR_REGISTRY"
```

---

### Step 3: Authenticate Docker to AWS ECR
ECR uses temporary authentication tokens generated by AWS IAM:
```powershell
aws ecr get-login-password --region $AWS_REGION | docker login --username AWS --password-stdin $ECR_REGISTRY
```
Output:
`Login Succeeded!`

---

### Step 4: Tag and Push Your Image
```powershell
# Tag local image with full ECR registry URL
docker tag diagnostic-api:v1 "$ECR_REGISTRY/$REPO_NAME`:latest"
docker tag diagnostic-api:v1 "$ECR_REGISTRY/$REPO_NAME`:1.0.0"

# Push image to AWS ECR
docker push "$ECR_REGISTRY/$REPO_NAME`:latest"
docker push "$ECR_REGISTRY/$REPO_NAME`:1.0.0"
```

Your container image is now stored securely inside AWS private infrastructure!
